기존 게임의 실시간 자동 전투 — Phaser 렌더러

이전의 임시 AI가 아니라 기존 본게임의 전투 판단·타격·필살기·승패 계산 함수를 그대로 가져와 실행해. 그림은 별도 Phaser 화면이며, 출전·보상·세이브 저장은 아직 연결하지 않은 읽기 전용 연습전이야.

사육장 실험실
한 번에 한 종씩 선택하되 여러 종을 연속 등록할 수 있어 (최대 6종, 총 48MB). 등록한 종은 각자 자기 모션으로 싸우고 미등록 종만 임시 그래픽을 사용해. 같은 종을 다시 선택하면 해당 종만 교체돼. 현재 탭 메모리 전용이며 원본 세이브와 서버에는 저장되지 않아.
엔진 초기화 중…
기존 HTML 게임의 실제 전투 판정 함수를 가져왔어. 현재 Phaser는 전투 결과를 원본 세이브에 저장하지 않는 별도 시연 화면이야. 디지몬별 그래픽은 로컬 파일로만 불러오며 공개 배포본에는 포함하지 않아.
