# 사육장 자동생활 안정화 — 2026-10-29

본게임의 전투 밖 플레이 루프(자율 이동·훈련·휴식·먹이·일자 변화)를
**기존 육각형 사육장 규칙 그대로** 유지하면서 아래 오류를 수정한다.
능력치 변화, 실제 전투, 진화 조건, 세이브 버전은 바꾸지 않는다.

## 수정된 동작

- **유실(lost) 디지몬은 활동하지 않는다.** 사육장 훈련 명령, 시설 자리
  점유, 배고픔 증가, 바닥 먹이 선점, 운동·휴식과 자동 이동에서 제외한다.
  유실 이전에 달리던 행동 예약은 취소하고, 이미 획득한 능력치·성장 기록,
  고유 `instanceId`와 저장된 개체 객체 자체는 보존한다.
  유실 상태가 된 개체의 바닥 먹이 예약은 해제하여 살아 있는 다른
  디지몬이 먹을 수 있게 한다.
- **자동 먹이 선점은 일정 배고픔(15 이상)**에서만 시작한다.
  완전히 배부른 디지몬은 떨어진 먹이를 낭비하지 않는다.
  또 HP가 최대의 40% 미만 또는 피로 65 이상이면 자유 상태에서
  먹이보다 회복 이동을 우선한다. 플레이어가 이미 내린 훈련 명령은
  기존대로 보호한다. 수치 15는 원작 ROM 확정치가 아닌 UX 임시값이다.
- **손상된 저장 시간으로 인한 프리즈를 차단한다.**
  저장된 `world.accumulator`가 NaN/Infinity/과도한 값이면
  진행되지 않은 일부 프레임 시간만 초기화한다.
  `advance`에 NaN/Infinity/음수/0이 들어오면 시계를 움직이지 않는다.
  비정상적으로 거대한 양수 델타도 1회 최대 300초로 제한한다.
  원래 브라우저 게임은 1프레임 0.15초까지만 넘기고,
  기획상 앱을 닫은 기간의 **오프라인 자동 육성은 하지 않는다**.
  정상 1x/2x/4x 배속과 240초 DAY 주기는 그대로 유지된다.

## 동일 소스/게임 파일 정합성

`src/farm-core.js`가 유일한 로직 원본이다.
`python3 tools/sync-embedded-farm.py`가 실제 플레이하는
`index.html`과 `standalone.html`에 **동일 코드를 내장**한다.
GitHub Action `sync-farm-branch.yml`이 PR 작업 브랜치에 동기화 커밋을
추가하며, `verify-farm-sources.yml`이 원본·내장 코드가 동일한지
검사한다. 이전 세이브 JSON 및 전투 전용 코드에 새 필드는 없다.

## 회귀 테스트

```bash
node --test tests/farm-life-safety.cjs
node tests/farm-core.cjs
node --test tests/farm-navigation.cjs tests/farm-avoidance.cjs
python3 tools/sync-embedded-farm.py --check
python3 tests/farm-life-browser.py
```

새 테스트는 유실 디지몬과 보관소 개체가 그대로 남는지, 유실 뒤 먹이
예약을 다른 개체가 가져갈 수 있는지, 충분한 배고픔·응급 휴식 우선순위,
손상된 누적 시각, JSON 재개 및 실제 PC/모바일 터치 브라우저 게임의
먹이/훈련 흐름을 검증한다.

**아직 별도 작업:** 실제 Android 기기에서 1~2시간 연속 실행, 본게임
사냥 포획 UX 보완, 훈련 미니게임/추가 시설 및 ROM 기반 정량 밸런스.
