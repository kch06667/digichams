# 실시간 전투 모션 보완 — 작은 단계 1 (2026-10-29)

## 목적

Phaser 미리보기는 원본 `DCOriginalArenaCore`의 **실시간 자율전투 AI**를 이미 재사용한다. 그러나 사용자가 개인적으로 가져온 스프라이트에는 모든 액션 이미지가 있지 않을 수 있다. 기존에는 해당 액션이 빠지면 대기 모션으로 대체되어 타격·피격·기절이 잘못 표현되었다.

## 이번 변경

- `phaser-lab/logic.js`의 `motionAction`이 원본 엔진의 `f.pose`를 먼저 존중하고, 없는 액션만 가까운 동작으로 대체한다.
- 우선 순위: 기절 `37 → 5 → 0`, 승리 `30 → 28 → 0`, 피격 `5 → 31 → 0`, 일반 공격 `7~10 → 0`, 필살기 `33 → 10 → 7 → 0`, 이동 `2 ↔ 3 → 0`.
- 전용 기절 애니메이션 `37`이 없는 개체는 기절 시 아래로 기울어져 쓰러진 형태로 표현한다. `37` 이미지가 있으면 원래 애니메이션을 그대로 사용한다.
- 사용자가 올린 종별 그림이 존재한다면, 다른 종의 그림이나 절차적 모양으로 덮어쓰지 않고 그 종의 사용 가능한 프레임으로 유지한다.

## 검증과 한계

`tests/phaser-lab.cjs`에 부족한 액션 집합과 기절·피격·공격·승리·필살기 대체 테스트를 추가. `tests/phaser-browser-smoke.py`가 원본 AI 전투 종료 뒤 실제 화면 스프라이트의 기울기를 확인한다.

전투 AI·판정·실시간 틱·피해·넉백 **계산**, 세이브와 기존 `index.html`, `standalone.html`은 변경하지 않는다. ROM 파일/개인 스프라이트를 GitHub에 업로드하지 않는다.

- 필살기 준비 → 발사 → 피격 시점 렌더링 검증
