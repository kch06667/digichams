# 2026-10-29 — 사냥 포획 재접속·터치 안정성

사육장/전투/챔피언십 규칙은 그대로 두고 원작형 로프 포획 UI를 개선한다.
원작 NDS의 정량 밸런스나 물리 판정 완전 복원은 아직 아니다.

## 플레이 변경

- **진행 중인 사냥 자동 보존:** 탐색·로프 선택·원 그리기 성공·미끼·
  당기기·HP 0의 기절 상태를 `state.huntSession`(version 1)에 기록한다.
  로프/먹이·팀은 기존 `state`에 그대로 기록한다. 저장 후 탭을
  닫았다 열어도 남은 타이머, 같은 야생 디지몬의 HP·좌표·로프 소비가
  복원된다. 화면이 꺼진 기간의 **오프라인 타이머 진행은 없다**.
  진행 중인 야생 사냥은 최대 3초마다 남은 시간을 기록하며, 브라우저
  `pagehide` 이벤트에서도 저장한다.
- **포획 정확히 한 번:** HP 0/기절이 아니면 포획할 수 없고, 신규
  개체 생성이 정상적으로 끝난 뒤에만 포획 처리한다. 성공 즉시
  `wild`와 `huntSession`을 해제하고 기존 저장소에 저장한다.
  포획/도주 완료 상태의 세션, 이름/HP/타이머가 유효하지 않은
  가져온 JSON은 복원하지 않는다.
- **입력 안전성:** 같은 포인터가 시작한 원/당기기 제스처만 이어간다.
  두 번째 손가락·다른 포인터의 올리기/취소 입력은 진행 중인 제스처를
  끝내지 않는다. 스테이지에만 `touch-action: none`을 적용해 휴대폰
  스크롤이 포획 드래그를 끊지 않도록 한다.
- **명시적인 사냥 포기:** 탐색 버튼 옆 `↩ 사냥 포기` 버튼이 있다.
  진행 중에는 새 탐색을 누른다고 현재 사냥이 사라지지 않는다.
  포기하면 해당 사냥만 종료하고 야생 상태를 저장에서 비운다.
  이미 사용한 로프/먹이를 돌려주지는 않는다.
- **리셋/JSON 가져오기:** 다른 세이브가 주입되면 이전 사냥의
  제스처를 폐기하고 새 세이브의 `huntSession`만 검사하여 복원한다.
  v0.21 이전 `state.wild`만 남아 있는 저장은 복원 가능한 세션으로
  취급하지 않으며, 멈춘 야생 대상만 안전하게 해제한다.

## 코드와 테스트

- 원본: `src/hunt-core.js`, `src/hunt-ui.js`.
- 실제 두 게임의 기존 `hunt-v021-core`/`hunt-v021-ui` 블록은
  `python3 tools/sync-embedded-hunt.py`로만 교체한다. 양쪽 HTML
  모두 동일한 hunt 로직을 포함해야 하며, 불명확한 태그/헤더는
  수정을 거부한다.
- 순수 테스트 `node --test tests/hunt-resume.cjs`: 정상 wild/tied/
  stunned 상태, 이중 포획 불가, 손상된 세이브 거부.
- 실제 브라우저 `python3 tests/hunt-browser.py` 및
  `python3 tests/hunt-resume-browser.py`: 기존 마우스/터치
  포획, 묶인 상태 새로고침 → 남은 HP·로프 복원 → 기절·포획 →
  새로고침 후 단 한 마리 유지 → 포기 및 재탐색.
- 원본 ROM·추출 애니메이션은 새로 공개 저장소에 추가하지 않는다.
  세이브 파일 백업을 권장하며, 테스트는 Chromium 데스크톱·터치
  에뮬레이션이다. 실제 Android 기기 장시간 테스트는 추후 과제.
