# 2026-10-29 — 실제 본게임 전체 플레이 흐름 수락 검사

## 목적

기존 테스트가 사냥, 육성, 진화, 일반 자동전투, 챔피언십, JSON 저장을
**각각 별도 초기 세이브**로 점검했던 한계를 보완한다. 이제
`tests/full-game-journey-browser.py`가 **하나의 세이브**로 모든 단계를
연속 진행한다. 테스트는 실제 `index.html`과 `standalone.html`에
포함된 기존 시스템의 API와 버튼을 사용한다.

각 파일을 **PC(1280x800)와 모바일 터치(390x844)**에서 검사한다.
총 4가지 독립 브라우저 환경을 테스트한다.

## 수락 시나리오 (실제 로컬스토리지 및 원본 게임)

1. 기본 코로몬이 있는 첫 실행, 로프 개수 검사.
2. 실제 탐색 버튼·로프 선택, 마우스 또는 터치 이벤트로
   **원형 포획 제스처** 입력, 로프 1개 차감.
3. 묶인 상태로 **실제 브라우저 새로고침**. 같은 야생 디지몬,
   타이머/로프 소비 상태, 이전 사육장 인원수가 보존되는지 확인.
4. 원본 당기기 제스처와 기절 → **포획 버튼**. 동료가 정확히 한 번
   추가됐는지, 새로운 고유 `instanceId`가 있는지 확인.
5. 포획한 디지몬을 사육장 명령 목록에서 선택하고 공격 훈련을
   시작해 `DCHexFarm.tick`으로 **기존 시간을 진행**.
   훈련/공격 능력치가 실제로 올랐는지 확인.
6. 초기 코로몬을 다시 선택, 기존 진화 목표 버튼에서 **아구몬**
   지정. 부족한 전투 3회 안내 확인.
7. **기존 저장 버튼 → 실제 새로고침** 후 포획 개체의 ID·능력치와
   초기 개체의 진화 목표가 보존됐는지 확인.
8. 실제 기존 1대1 보유 개체 전투 3회에 출전해,
   원본 전투 정산으로 전투/승리 기록과 경험치를 받음.
   목표 진화로 **코로몬 → 아구몬** 진화하며 ID가 보존되는지 확인.
9. 실제 신인 챔피언십 참가 버튼, **준결승 → 결승** 두 경기를
   완료하고 1회 우승·트로피·상금 지급 확인.
10. 다시 **브라우저 새로고침**, 보유 2마리·진화한 아구몬·
    포획한 디지몬·승률 기록·대회 보상·로프·임시 전투 상태 확인.
11. 정상 JSON **세이브 내보내기 → 가져오기**로 고유 ID,
    능력치·로스터·챔피언십 기록 및 자동 생성한 백업 유지 확인.
    가져오기 이후 다시 새로고침하여 동일 기록 유지.

## 검증 방법

```bash
python3 -m pip install playwright==1.57.0
python3 -m playwright install chromium
python3 tests/full-game-journey-browser.py
```

전투에서만 **테스트용 훅으로 상대 HP를 0으로 만드는 방식**을 사용해
일반전 승패와 챔피언십 진출을 결정론적으로 진행한다. 이것은 본게임
HTML을 수정한 것이 아니라, 로컬 HTTP 테스트 서버가 응답에만
주입하는 훅이다. **공격 AI의 진짜 전투 수행 시간·실력과 물리적
기기 성능까지 검증했다는 뜻은 아니다.** 그런 부분은 별도의
Phaser 및 실제 Android 성능 테스트로 남긴다.

포획에는 실제 포인터 제스처, 진화·전투·대회 승리에는 기존 정산,
훈련에는 기존 사육장 시뮬레이션, 저장에는 로컬스토리지와 원본
JSON 아카이브/백업을 사용한다. 사용자 ROM·개인 그래픽·세이브
자료를 CI에 올리지 않는다.

## 결과

첫 CI에서 원본 `index.html` PC 및 `standalone.html` 모바일 터치가
통과했고, 확대 검증에서 **두 HTML × 두 입력 환경 = 4개 전부 통과**.
포획·진화·챔피언십 등 통합 상태에서 신종 오류는 발견되지 않았다.
따라서 이번 PR은 **게임 규칙 수정이 아닌 장기 회귀 방지 테스트/CI**다.
수상한 문제가 없는데 임의로 기존 코드를 다시 쓰지 않는다.

향후 원본 사육장·포획·진화·대회와 관련된 코드가 바뀔 때
`.github/workflows/full-game-journey.yml`은 수락 검사를 다시 실행한다.

### 미검증 사항

- 실제 Samsung/Android 기기에서 1–2시간 이상 장시간 실행,
  앱 종료 및 메모리 복귀, 백그라운드 전환

- NDS ROM과 모든 수치/애니메이션/AI를 일치시키는 검증
- 공개 일반 게임 `index.html`의 옵션 Phaser 전투 정식 전환
