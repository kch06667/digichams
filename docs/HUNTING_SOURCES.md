# NDS Digimon World Championship hunting references (v0.21.0)

Confirmed by 2008-era guides/reviews:
- https://gamefaqs.gamespot.com/ds/943756-digimon-world-championship/answers/3146-how-do-i-use-the-rope-for-hunting — draw one quick circle and lift stylus, then pull/release repeatedly to avoid snapping.
- https://gamefaqs.gamespot.com/boards/943756-digimon-world-championship/45836974 — drain the roped target HP, then select the hand tool to grab. Hunting capacity also needs memory upgrades.
- https://worthplaying.com/article/2008/11/2/reviews/56292-nds-review-digimon-world-championship/ — hunting zones, moving wild creatures, lasso, drag/hand tool.
- https://www.gamespot.com/articles/digimon-world-championship-first-look/1100-6189379/ — region, season, time and weather influence spawns; bait and traps exist.

Implementation scope in v0.21.0: normalized-geometry rope tool, roaming/escape timer, staged pulls and pickup, 3 illustrative zones and simple bait.
