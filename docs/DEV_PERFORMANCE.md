# 개발용 성능 진단 (2026-10-28)

`main` 게임 세이브 및 실제 배포 HTML은 변경하지 않는다. 개발용 HTML 생성기만 개발 전용 모니터를 추가한다.

## 실행

```bash
npm run dev:build
python3 -m http.server 8000 --bind 127.0.0.1
```

`http://127.0.0.1:8000/index.dev.html?perf=1` 열기.

오른쪽 아래 성능 상자에 FPS, 최근 2초 최대 프레임 지연, Long Task 발생 횟수, 이미지 네트워크 요청 건수/전송량, 지원되는 Chromium의 JS 힙 사용량이 표시된다. 닫기 버튼으로 측정을 중지한다. `?perf=1` 없이 열면 측정/상자가 동작하지 않는다.

**주의:** FPS는 별도 `requestAnimationFrame`으로 측정한 렌더링 주기 지표이며, 게임 로직 자체의 FPS나 실행 속도를 확정하는 수치는 아니다. Long Task API 및 `performance.memory`는 브라우저별 지원 차이가 있다. 캐시된 이미지의 전송량은 0으로 보일 수 있다. 숫자를 비교할 때 같은 기기/게임 화면/브라우저 캐시 조건에서 측정한다.

## 검증과 제한
- 기존 `index.html`·`standalone.html`·게임 로직/세이브 관련 파일은 수정하지 않았다.
- 로컬 동등 개발 페이지 빌드 Node 4/4 테스트 통과. 최신 GitHub 브랜치의 CI와 실제 Android 장시간 측정은 별도 검증 필요.
- v0.23.2 이미지의 최신 `main` 그래픽 적용은 이 진단 기능과 별도 단계이고 **아직 완료되지 않음**.
