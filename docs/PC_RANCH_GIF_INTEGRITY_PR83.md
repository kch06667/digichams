# 11차 — 원본 GIF 애니메이션 자산 검사와 PC 복구

## 목표
**기존 디지몬 216종 완성도**를 먼저 높입니다. 신규 종/모션/원작 ROM 개조/공개 자산 배포는 진행하지 않습니다.

## 발견 사항
업로드한 사용자의 v0.23.2 플레이용 ZIP에서 기존 `assets/sprite-index.json` 목록을 확인했습니다.
카탈로그는 디지몬 **216종 + 디지타마 8종**이며, 일반 디지몬당 40포즈를 참조합니다.
기존 `spriteUrl()`의 **유니몬 5번 포즈 → 4번 포즈 별도 처리**는 그대로 유지합니다.
이는 원본 카탈로그에 기반한 검증으로, 새로운 디지몬이나 미확인 모션 번호를 도입하는 작업이 아닙니다.

## 구현
- `tests/sprite-gif-integrity.cjs`: 디지몬 216종 및 8,640개 해석된 GIF 경로
  존재, GIF87a/GIF89a 헤더, 양의 가로·세로, 파일 종료 마커를 확인합니다.
- `src/pc-ranch-sprite-guard.js`: 기존 PC 사육장 DOM에서 실제 이미지
  로드 실패 이벤트가 발생할 때, **같은 종의 0번 대기 GIF**로만 재시도.
  0번조차 실패하면 깨진 이미지 UI를 숨기고 상태를 `data-dc-sprite-recovery="missing"`으로 기록.
  다른 디지몬 이미지나 신규 그림, 원격 URL로 교체하지 않습니다.
- `src/pc-playability-guide.js`에 PC 전용 로딩을 연결해
  기존 게임의 920×690 사육장, GIF 로딩 방식, 세이브와 전투 로직을 유지합니다.
- `tests/pc-ranch-preview.cjs`: 원본 게임 Chromium에서 없는 포즈를
  시뮬레이션하고 아구몬의 실제 대기 GIF로 복원되는지,
  0번도 없는 경우 경고만 남기는지, 원본 플레이 세이브가 그대로인지 확인.
- 모바일/터치에는 PC 전용 복구 기능을 주입하지 않습니다.

## 배포 경계
사용자 Windows PC 장시간 플레이·시각 검수와 portable EXE 배포는
별도 검증 대상입니다. 모든 개발 PR은 검수 전 Draft 유지,
`main` 병합·원작 데이터 공개 업로드는 하지 않습니다.
