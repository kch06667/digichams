# PC 사육장 8차: 해금된 구역으로 자유 산책 (실험 기능)

## 목적
기존 `DCFarm`은 자동 산책 목적지를 중앙 사육장 안에서만 생성했습니다.
PC 전용 선택형 '🌿 자유 산책 켜기'를 추가해 명령받지 않은 디지몬이
이미 해금한 주변 시설 구역까지 자연스럽게 찾아가도록 했습니다.

## 플레이 방법
1. Windows/PC에서 실제 사육장 게임을 시작합니다.
2. 주변 시설을 건설하고, 사육장 상단의 **자유 산책 켜기**를 누릅니다.
3. 훈련 등 명령을 받지 않은 디지몬이 기존 이동 가능 구역과 통로를 따라
   해금된 시설 주변을 산책합니다. 미해금 구역에는 가지 않습니다.
4. 버튼을 다시 누르면 새 목적지 배정은 중지합니다. 이미 이동 중인
   산책은 목적지까지 마친 뒤 기존 자동 생활로 돌아옵니다.

## 기존 게임 보호
- 이 기능은 **기본 OFF**이며 PC 마우스 모드에서만 나타납니다.
- 별개인 '연결형 지형 시험 보기' 버튼은 여전히 **그래픽 전용**입니다.
- 새 경로/속도/충돌/먹이/훈련/진화 알고리즘을 중복 구현하지 않습니다.
  `DCFarm.advance()` 입구에서 유휴 디지몬의 자유 이동 목표만 설정하고,
  실제 이동/회피는 기존 사육장 엔진이 수행합니다.
- 수면/치료가 필요한 디지몬, 먹이를 먹으려는 디지몬, 수동 훈련/휴식,
  알/실종/보관 개체, 경기 중/일시정지 상태는 건드리지 않습니다.
- 난수 소비 없이 개체 ID와 게임 시간을 이용해 반복 가능한 목적지를
  고르므로, 동일 JSON 상태의 저장 후 재개 판정이 일관됩니다.
- 자유 이동 목표는 기존 `farm.actors[].goal` 형식을 재사용합니다.
  **새 저장 데이터 필드나 별도 설치·ROM 파일은 필요하지 않습니다.**
- 원작 환경별 진화/스탯 상승 효과는 분석·검증 전이므로 이 기능에 없습니다.
