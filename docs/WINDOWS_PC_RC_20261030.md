## Git 없이 내 PC에서 개인용 테스트 EXE 만들기
Windows 10/11 64비트, 여유 저장공간, 인터넷(최초 npm 설치 때), **Node.js LTS**가 필요합니다.

1. GitHub의 이 RC 브랜치에서 **Code → Download ZIP**을 선택합니다. 최상위 폴더 구조를 유지하여 전부 압축 해제합니다.
2. 압축을 푼 최상위 게임 폴더에서 PowerShell을 열고 다음 명령을 입력합니다.

   powershell -NoProfile -ExecutionPolicy Bypass -File ".\desktop\build-private-portable.ps1"

3. **개인용 테스트 EXE 경로:** \`dist\desktop\Digimon-Championship-0.24.0-rc.1-Windows-x64.exe\` (성공했을 때).
4. 기존 게임 저장을 덮어쓰기 전 게임의 **세이브 JSON 내보내기**로 별도 백업합니다. Windows Electron의 프로필 저장소는 브라우저/이전 ZIP과 별개일 수 있습니다.
5. 파일은 공개 GitHub Release, Actions 아티팩트, Discord 등에 재배포하지 않습니다. 코드서명 없이 만든 실행 파일은 Windows에서 보안 경고가 나올 수 있습니다.

Git은 필요 없습니다. Node/npm 또는 인터넷이 없으면 빌드가 실패할 수 있습니다. CI는 실행 파일을 로컬로만 생성하며 공개 파일로 배포하지 않습니다.

## RC 자동 검증 실행
- \`npm --prefix desktop test\` — Electron 런처, 안전한 프로토콜, 출시 전 자산 검사.
- \`npm --prefix desktop run test:release\` — 실제 원본 게임/육성/전투/Phaser 자산 + 216종 8,640개 GIF 경로 검사.
- Windows 통합 GitHub Actions에서 개발 Electron 게임, \`win-unpacked\` EXE, 실제 GIF, 정식 보관소 cold-start, packaged 자산 검사 및 **portable EXE 자체 빌드/PE 헤더/크기 확인**.
- 기존 브라우저/모바일/진화/Phaser/사육장/포획/컵 자동회귀를 그대로 재사용합니다.
- 테스트 통과는 원작 밸런스 100% 일치, 모든 모션 매칭, 개인 PC에서 바이러스 백신 허용, 게임의 모든 진행 경로 완주를 증명하지 않습니다.
