# 12차 — 진화 이후 사육장 위치·명찰·GIF 전환 복구

## 발견된 실제 오류
종이 바뀌면 기존 `hex-farm-ui.js`는 `spriteUrl`로 새 종의 이미지를
가리키지만, 같은 `instanceId`의 기존 DOM 버튼을 재사용하면서
**이름표(`span`)와 `title`이 이전 종으로 남았습니다.**
또한 `evolution-core.js`의 `transform`은 이전 이동 경로,
시설 예약, 음식 예약, 재개 목표를 완전히 해제하지 않았습니다.

## 변경
1. `src/hex-farm-ui.js`: 기존 디지몬 버튼의 이름표·선택 제목을
   실제 진화된 `m.name`으로 갱신. 클릭 및 저장·종족 추적은 이전과 동일.
2. `src/evolution-core.js`: 진화 시 같은 `instanceId`와 `x,y`
   위치를 보존하면서 이전 종의 시설 슬롯·이동 경로·먹이 예약·
   일시 중지된 훈련을 모두 해제한 뒤 0번 대기 포즈로 복귀.
   기존 진화 경로·필요 AP·능력치·진화 시기는 수정하지 않음.
3. `src/pc-ranch-evolution-fx.js`: PC 사육장에 이미 존재하는
   디지몬이 **실제로 다른 종으로 변경될 때만** 기존 GIF에 약
   1.1초 짧은 밝기 전환과 `이전 종 → 새 종` 표시.
   새 도트/새 포즈 매핑/원작 ROM 수정 없이 기존 렌더러 변화만 관찰.
   새로고침/세이브 불러오기의 첫 표시에는 연출 없음.
4. CSS는 기존 픽셀아트를 사용하며 시스템 `reduced-motion`
   설정에서는 효과를 끔. 모바일/터치에도 이 확장 스크립트를 적용하지 않음.
5. 세이브 데이터 필드나 키 추가 없음. 게임 메커니즘 변경은 진화 시
   **이전 명령 정리의 버그 수정**에만 제한.

## 검증
- `tests/pc-evolution-ranch-return.cjs`: 코로몬→아구몬의 실제
  기존 진화 함수를 호출해 인스턴스/좌표 보존, 음식 예약 해제,
  이전 이동·훈련 슬롯 반환, 이후 사육장 정상 동작과 저장 재현 확인.
- `tests/pc-ranch-preview.cjs`: 실제 원본 게임 PC DOM에서
  일시적인 이름 변경을 렌더링해 새 GIF·명찰·타이틀·진화 전환을 확인하고
  원래 이름과 전체 플레이 세이브 상태를 다시 복구. 모바일 미적용 확인.
- 기존 216종 GIF 무결성, 자동 생활·전투·전체 세이브 통합검사 회귀 유지.

## 남은 과제
이 효과는 **진화된 새 종의 원본 대기 GIF와 짧은 UI 연출**이지,
NDS의 정확한 진화 시퀀스를 완전히 추출하거나 복원한 것은 아님.
장시간 Windows 플레이·시각 품질 검수와 portable EXE 최종 배포는 별도.
새로운 디지몬·오메가몬 추가는 게임 완성 이후까지 보류.
검수 전 `main` 병합·원작 자산 공개 배포 금지.
