# 미확정 사항과 원작 검증 백로그

## 사용자 합의로 확정되었지만 숫자·규칙은 미정
- 육각형 하나의 슬롯 수/배치 제한/맵 크기/카메라 및 다중 육각형 연결 규칙.
- 초기 활동 G, 랭크/육각형 확장에 따른 G 단계, 최종 상한. **최종은 무한이 아님**. 과거 문서 200G는 원작 검증 후보.
- 시설별 상승/하락값, 주기, 확률, 최대 등급, 체력 안전선(20% 제안), 자동 휴식 임계치.
- 기술 훈련 시간, 보조 기술 슬롯 1~2개, 숙련·TP 보정, 진화·알 상속.
- 기질 25종의 실제 효과 매트릭스/이름/정확한 보정률, IV 0~31 분포/전투 보정치/디지에그 계승, 6V 확률/검사 UX.
- 디지몬 관계, 지원 보호 공격, 특별 합동기 대상/필요 TP·관계 임계치/쿨타임/연출.
- 3명 라이벌의 인물/파트너·퀘스트, 전문 테이머의 속성/순서, 챔피언 보스, 게스트 일정·보상.
- 퀘스트 총량, 자동 수주/완료·반복 임무의 갱신 규칙, 대사/보상 수치.
- 자동 육성 목표 도출 및 조건을 공개하는 UI의 상세/힌트 경계.
- 원작식 직접 수동 전투/SELECT 입력의 구현 범위.

## 원작 데이터 반드시 검증 (과거 위키 기반 주장)
- 종별 진화 조건식 AND/OR, 진화 판정 우선순위, 수명/진화 기억, 로스트/디지에그 분기, 진화 G.
- 타이틀 접수 마감 15시, 사냥 22시 종료, 계절/연간 대회 일정, 타이틀 반복 수익.
- 랭크 1~10, 엔딩 랭크 조건, 랭크별 시설/아이템/포획/진화 제한, 원작 최대 200G 표기.
- 원작 케이지 상·하락/선택 분포, 소요시간, 입장 점유(2/6), 진화/배고픔/질병/패널티 트리거.
- 각 기술/필살기/상성/저항/기술 특효, 직접 조작/한국판 vs 해외판 차이, 레거시 버그.
- NDS ROM에 들어있는 실제 종/애니메이션 상태/이펙트/배경·데이터 포인터, 누락 종과의 차이.
- '24 디지에그화' 번역이 실제 24G 참가 조건인지 원문/ROM 비교.

## 문서 충돌 해결 기록
- v0.4 원본의 '보관소 내 시간 정지는 미확정': **이후 합의에서 무제한 보관소 + 수명/상태 동결 확정**으로 갱신.
- v0.4 원본의 '다중 육각형 G 증가 방식 미확정': **확장과 함께 활동 수용량 증가 / 최종 상한 유지**는 방향 확정. 구체 숫자만 미정.
- v0.4 원본의 3개 배틀 지시/직접 조작은 구설계: **신규 팀/개별 6전술이 우선**. 원작 직접 조작은 별도 검증/후순위.
- 예전 일자 복도형 사육장: **사용자가 컴팩트 육각형→다중 연결로 변경 확정**.
- 최신 개체차/고정 라이벌/퀘스트 B는 v0.4 원본 이후 결정된 내용: `PROJECT_BRIEF_LATEST.md` 우선.
- '모든 진화는 2개 조건', '훈련은 상승만', '무조건 디지에그화' 등의 과거 단순화는 사용 금지.
