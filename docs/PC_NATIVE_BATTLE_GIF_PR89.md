# 17차 — Phaser 실전 전투에 216종 원본 GIF 자동 적용

## 기존 문제와 해결
16차까지 게임 내 Phaser 전투는 원본 GIF를 별도 도구로
PNG spritesheet로 사전 변환해 `phaser-lab/local-assets`에
저장한 종족만 자동 표시했습니다. 변환 자료가 없으면 원본
GIF 216종·8,640개가 게임 폴더에 이미 존재해도 임시 도형을
표시할 수 있었습니다.

이번 17차는 **기존 원본 GIF를 브라우저가 그대로 애니메이션
재생**할 수 있도록 보조 렌더링 층을 연결합니다. 기존 HTML
게임에서 이미 쓰는 자산만 참조하므로 새로운 도트나 ROM
추출물은 필요하지 않습니다.

## 실제 변경
- `phaser-lab/native-gif-layer.js`:
  `assets/species-catalog.json`과 `assets/sprite-index.json`
  **두 실제 원본 색인**을 일치 대조하여 **216종 한국어 이름 →
  유일한 파일 폴더·stem**으로 매핑합니다.
- 동일 종의 `0~39` 모션 중 **실제로 사용되는 포즈**만
  `../assets/sprites/<종족>/<파일명>_<포즈>.gif`에서 로드.
  원본 피격 유니몬은 `5_1.gif` 적용. 가짜 종족/경로 혼입
  방지 검증. 필요 없는 8,640개 파일 전체 로딩은 금지.
- 실제 참가한 최대 6마리만 Phaser 캔버스 위의 별도
  `<img>`에 매핑하고, 원본 전투 `DCOriginalArenaCore`의
  **실제 위치·방향·공격/피격/KO 포즈**와 화면 크기를 매 프레임
  일치시킵니다. 화면에 원본 GIF가 정상 로딩되면
  해당 참가자의 기존 임시 도형만 숨깁니다.
- 파일 로드가 실패하면 해당 종의 원본 대기 GIF 한 번 시도.
  그것도 실패하면 기존 임시 도형을 **안전하게 복구**합니다.
  다른 디지몬을 대신 보여 주지 않습니다.
- 개인이 직접 만든 PNG atlas가 있으면 기존 해당 종의
  Phaser 애니메이션을 **우선** 사용. 기존 atlas 로직을
  덮어쓰거나 제거하지 않습니다.
- 화면 재시작·1v1↔3v3 전환 시 이전 종의 이미지를 제거하고,
  원본 코드가 소유한 **전투 판정·AI·TP·저장·챔피언십·연출
  카운터**를 변경하지 않습니다.
- `DigiPhaserLab.stageStatus()`의 `nativeArt`,
  `renderedArt()`의 `nativeArt/nativeGif/nativePose`로
  실제 표시 상태를 읽기 전용으로 확인할 수 있습니다.
- `phaser-lab/index.html`에서 모듈을 전투 코드보다
  먼저 로드합니다. 기존 Windows 배포물에 새 파일이
  포함되는지 확인합니다.

## 안전성과 검증
- `tests/phaser-native-gif.cjs`: 216종 이름·stem 일치,
  216×40=8,640개 원본 GIF 실제 경로/존재 여부,
  유니몬 예외/경로 조작/오프라인 대응 검사.
- `tests/phaser-native-gif-browser.cjs`: 실제 Chromium
  PC/터치에서 변환 PNG 없이 **3v3 6마리 원본 GIF 로드 →
  자동 공격 모션 전환 → 1v1 새 경기 → 전투 종료** 검증.
- `.github/workflows/phaser-native-gif.yml`: Phaser 3.90.0
  로컬 공급으로 브라우저 CI를 재현하고 실제 이미지 로딩 검사.
- Windows 전용 release preflight에도 모듈 및 216종
  파일 경로 검사를 추가했습니다.

## 제한
원본 GIF를 가지고 있는 **정상 설치된 PC 전체 게임**에서
동작합니다. 별도의 GIF 파일 없이 HTML 한 파일만 복사하면
원본 이미지 경로를 읽을 수 없어 기존 대체 표시가 나올 수
있습니다. 이 구현은 HTML 이미지 렌더링 계층을 사용하므로
Phaser 캔버스 단독 스크린샷이나 엔진 내부 텍스처로 사용되는
PNG atlas와 구조가 다릅니다. GIF 프레임 지속시간은
브라우저 원본 GIF 재생 엔진이 처리합니다.

모든 216종의 기술·이펙트 의미나 원작 NDS 밸런스·전투
자세의 100% 검증을 의미하지 않습니다. 사용자 실제 PC
장시간·시각 테스트는 남았고, 원작 자산 배포 권리 확인 전
EXE/ROM/이미지 공개 업로드는 하지 않습니다.
