## 1. 검증된 것과 검증되지 않은 것

- PR #78 자동 CI에서 Windows **Electron 개발 창 및 unpacked EXE** 실행,
  `digichamp://game/` 리소스 로딩, 920×690 사육장, 초원 A/B 전환,
  렌더러 격리, 임시 localStorage 키의 **새로고침 후 유지**를 검증했습니다.
- 후속 PR의 `desktop/tests/electron-smoke.cjs`는 같은 격리 프로필로
  **Electron 프로세스를 완전히 종료한 뒤 재실행**하여 임시 키가 유지되는지도 검사합니다.
  이는 로컬 저장소의 지속성을 검증하되, 실제 플레이어 저장 파일의
  전체 육성·진화·전투 무결성을 대신하지 않습니다.
- **단일 파일 portable EXE** 완성 빌드, Windows Defender 경고,
  사운드/애니메이션 자연스러움, 실제 장시간 육성·전투, 사용자의 PC 화면은
  아직 완료로 취급하지 않습니다.

## 2. 사용자가 확인할 실제 화면 (PC 우선)

1. Windows 창(1366×768 및 가능하면 1920×1080)에서 타이틀, 버튼,
   사육장 정보, 시설 관리가 웹사이트처럼 어색하게 겹치지 않는가.
2. 원래 사육장/연결형 초원 버튼을 각각 켜고, 그래픽이 원작 분위기와
   자연스럽게 어울리는지 확인합니다. 시설 앞/뒤 가림과 디지몬 그림자,
   명찰, 먹이 선택 및 이동을 특히 확인합니다.
3. 사육장에서 식사 → 훈련 → 휴식 → 진화, 포획 → 전투 → 챔피언십의
   **한 저장 파일** 플레이를 진행합니다. 단순 시연 캐릭터나 별도
   전투 데모가 아니라 기존 실제 게임 탭을 사용합니다.
4. 저장 JSON을 내보내고 게임 종료 후 다시 실행한 뒤, 디지몬 종류,
   성장 상태, 시설/Bit/대회 기록을 확인합니다. 구버전 세이브를
   덮어쓰기 전에 백업 파일로 복원 가능 여부도 확인합니다.
5. 원작에서 검증하지 못한 환경별 육성·진화 수치와 자유 생활 AI는
   완성 기능으로 표시하지 않습니다.

각 PR은 누적 변경을 포함한 **stacked PR**입니다. 앞 PR을 무작정
`main`에 병합하고 뒤 PR도 원래 base로 병합하면 중복/충돌 위험이 있습니다.
사용자 시각 검수와 CI 통과 이후 **순서대로 base를 갱신하거나
하나의 검증 완료된 통합 변경으로 정리**하여 병합해야 합니다.
각 단계에서 기존 자동 사육장/포획/진화/Phaser 전투/세이브 테스트를 보존합니다.

## 4. 배포 전 제한

GitHub Actions의 로컬 검증 결과와 공개 배포 가능한 게임은 별개입니다.
원작 ROM/저작권 있는 이미지·사운드가 포함된 EXE/ZIP은 권한 확인 전
공개 릴리스나 공개 아티팩트로 업로드하지 않습니다.
