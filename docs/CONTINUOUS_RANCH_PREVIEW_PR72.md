# PR #72 — 연결형 자연 사육장 시험 화면 (2026-10-30)

## 목표와 확정된 디자인
- 사용자는 NDS 월드 챔피언십 기반 원작 육성·진화·전투를 보존하면서 **넓은 중앙 공용 목장 + 외곽 자연 서식지**를 단일 화면으로 자연스럽게 연결하기로 선택했다.
- 디지몬은 플레이어가 육성 환경에 배정하며, 그 환경을 중심으로 여러 마리가 공동 자유 생활한다. *현 단계에서는 설계 확정이고 구현은 아직 아니다.*
- 실제 환경의 종류·환경별 육성/진화 조건·수용 제한은 원작 ROM과 현재 게임 상태 모델의 정밀 검증 이후 적용한다.
- 배변·청소는 원작 확인 후 직접 청소 및 후기 자동화 해금을 재검토한다. 새 육성 효과를 임의로 추가하지 않는다.

## 안전한 2차 프리뷰 구현
- 부모 작업: PR #70 (브랜치 `ui/pc-shell-issue-69`). PR #72는 그 브랜치를 base로 한다. **둘 다 draft, main 미병합**.
- `assets/farm/continuous_ranch_preview.svg`: 920×690 **오리지널** 지형 표시. 중심 초원과 바깥의 숲/바위/연못/열기 있는 지형 디자인. 법적 출처가 필요한 신규 ROM 아트 없음.
- `src/pc-continuous-ranch.css`: `#farmPanel .farmWorld`의 배경만 시각적으로 교체한다. 기존 v0.23.2 WebP에서 시설 파사드 부분을 CSS 마스킹해 유지한다. 7개 기존 시설 버튼의 좌표/ID/상태는 바꾸지 않는다.
- `src/pc-continuous-ranch-preview.js`: 데스크톱 PC에서 '연결형 지형 시험 보기'를 통해 켜기/끄기. 클래스 `dc-ranch-continuous`만 전환하며 상태와 저장 데이터에는 쓰지 않는다. 새로고침 시 기존 배경으로 복귀.
- `src/pc-playability-guide.js`: 이미 존재하는 PC 전용 부트스트랩에서 프리뷰 JS 로드.
- `tests/pc-ranch-preview.cjs`: 실제 `index.html`을 1366×768/1024×768 Playwright 브라우저에서 연 뒤 기존 좌표·7개 시설·개체/먹이·저장 데이터를 보존하는지 검사. 모바일 터치에서는 위 기능이 로드되지 않는지 확인.
- `.github/workflows/pc-ranch-preview.yml`: syntax + 기존 농장 회귀 단위 검사 + 실제 브라우저 토글 검사.
- 부모 PR #70의 PC 셸이 이미 와이드인 경우 구 NDS 전환 버튼이 숨겨져 있다는 사실을 반영하여 `tests/phaser-production-default-browser.py`의 오래된 테스트 가정을 정비했다. **게임 전투 로직 변경 없음**.

## 원작 코드와 좌표의 실제 사실
- 실제 7개 시설 중심 좌표는 `src/hex-farm-ui.js`에 있고, 월드 크기는 920×690이다.
- 기존 이동/먹이 좌표 변환과 훈련 명령은 `src/farm-core.js` 및 `src/hex-farm-ui.js`에 유지된다. 이 PR에서 해당 소스는 수정하지 않는다.
- 시설 구입·해금, 디지몬 경로, 회피 및 원작 훈련/진화 판정은 **전부 기존 구현**.
- 이 SVG 안의 주변 지형은 **아직 실제 육성 환경 판정과 연결되지 않은 디자인**이다. 화산/고산 등으로의 환경 배정이 이미 구현됐다고 주장하지 않는다.
