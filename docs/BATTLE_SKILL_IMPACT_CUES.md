# 실시간 자율 전투: 필살기·넉백 화면 표현 2차 개선 (2026-10-29)

## 변경 배경

Phaser 시연 화면은 `src/arena-original-core.js`에서 추출한 원본 웹게임의 전투 AI와 판정을 사용한다. 기존에는 준비 표시 조건이 `f.act==='cast'`였으나 실제 원본 엔진은 `f.act==='special'`을 사용해 준비 링이 표시되지 않았다.

## 수정 범위

- 실제 `act==='special'`·`pose===33`일 때 **필살기 준비 링**, `pose===10`일 때 **발사 방향과 충격 강조 표시**가 나타난다. 원본 전투 엔진의 자세가 바뀌면 표시도 자연스럽게 사라진다.
- **발사체의 실제 이동·궤적과 명중 판정**은 기존 `src/arena-original-core.js`의 `bullets`, `projectiles`, `hit` 이벤트를 그대로 렌더링한다. 가짜 명중이나 추가 피해를 생성하지 않는다.
- 피격 후 실제 `knockVX`가 발생한 디지몬 스프라이트는 ±14° 내에서 해당 방향으로 기울어지고, 원본 넉백 속도가 줄면 원위치로 돌아온다. 기절 전용 모션 또는 누운 자세는 기존처럼 우선한다.
- 추가 그래픽 리소스·ROM·개인 스프라이트는 커밋하지 않는다. 전투 수치·AI·세이브·기존 본게임 HTML 모두 그대로다.

## 검증

`tests/phaser-lab.cjs`는 준비/발사 상태와 넉백 각도의 수학적 경계, 가드·기절 상황을 검사한다. `tests/arena-original-parity.cjs`에서는 실제 원본 AI를 시뮬레이션해 준비/발사/필살기 명중/넉백 상태가 생성되는지 확인한다. `tests/phaser-browser-smoke.py`는 PC·모바일 터치 에뮬레이션으로 동일한 순서를 읽기 전용으로 검사한다.

이 개선은 Phaser 미리보기 전용 시각적 피드백이다. Android 실기 체감·원작 NDS 모션의 픽셀 일치·모든 기술의 연출 정확성은 아직 검증되지 않았다.
