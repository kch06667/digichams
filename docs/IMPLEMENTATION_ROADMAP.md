# 단계별 구현 로드맵 — 대규모 원샷 개발 금지

## Stage 0 — 현황 감사, 기본 프로젝트 셋업
- 기존 v0.14 압축 해제; 실제 엔트리/스타일/게임 루프·GIF/JSON 자산·현재 기능 스크린샷과 실행 검증.
- 기술 구조 선정, 실행·빌드/테스트 명령 문서화, 초기 회귀 테스트 작성.
- 원작 검증 매트릭스/불확실성 목록 작성. ROM 미제공이면 ROM 검증 업무는 블로킹하지 말고 별도 후속 과제로 유지.
- 산출물: `CURRENT_STATE_AUDIT.md`, `TECHNICAL_ARCHITECTURE.md`, `VERIFICATION_BACKLOG.md`, 실행 가능한 최소 프로젝트.

## Stage 1 — 사육장 플레이 가능 수직 슬라이스 (가장 먼저 실제 코딩)
- 컴팩트 육각형 하나, 중앙 생활 공간, 훈련·먹이·휴식/치료 기본 슬롯.
- 알 1개→부화/등장(종별 임시 데이터 가능)→기본 자율 이동/먹이·휴식.
- 선택→시설 클릭 / 선택→훈련 메뉴, 실제 이동/예약/훈련 반복·중단 및 애니메이션 종료시 HP/스탯 변화.
- 정지/배속·저장/불러오기·간단한 상태 UI·PC/Android 터치 대응.
- 검수: 실제 브라우저에서 플레이, 클릭 중복 보상 금지, 저장 재개 가능, 단일 육각형으로 기본 루프 완결.

## Stage 2 — 핵심 원작 메커닉
- ROM·영상·위키 대조 진행하며 시설 상승/하락, HP·스트레스·병·수명, 성격 8종, G, 보관소.
- 실시간 사냥/로프/도구/포획, 원작 디지몬 데이터/진화 조건/디지에그·진화 기억/로스트.
- 원작 AI 전투·상성/TP/특수기·대회 및 랭크·상점/시설 해금/연간 스케줄·도감.
- 원작 타이틀 및 챔피언십에 도달 가능한 완주 흐름을 검증. 원작 정보 미검증은 provenance 명시.

## Stage 3 — 육성 편의·확장 기초
- 시설 강화, 다중 육각형 확장, 활동 G 단계 증가/최종 상한.
- 목표 능력치 자동 육성→고급 진화 목표 기반 자동 육성, 고급 휴식·훈련 미니게임/스킵.
- 별도 25기질·6 IV(영향 작게), 보관소 스테이시스, 기술 훈련소·기술 숙련.
- 팀/개별 6전술, 관계·일반 지원/보호/연계 공격.
- 원작 진행/밸런스가 깨지지 않도록 회귀 테스트.

## Stage 4 — NPC·퀘스트 및 엔드게임
- 공격형/전략형/유대형 고정 라이벌 3명 + 시간·전적·랭크 기반 성장/재대결/방문.
- 전문 테이머 선택형 시험, 챔피언 보스, 애니 게스트(로스터/권리/공식 설정 대조).
- '라이벌 스토리 + 자유 의뢰' 퀘스트, 해금·보상·저장·중복 방지.
- 원작 엔딩 후 확장 챔피언 리그 및 랜덤 합법팀 NPC.
- 특정 관계/종에만 고유 합동 필살기 및 연출, 사육장 심층 관계 이벤트.

## Stage 5 — 고도화·QA
- 랭크/계절/세대/시간 흐름·사냥/진화·원작/확장 분리까지 E2E 테스트.
- UI/접근성·모바일 터치성능·세이브 마이그레이션·기기 반응형.
- 데이터/자산 provenance 감사, 권리·개인 배포 범위 점검.

## 매 단계 완료 기준
- 플레이 가능한 결과물이 실제 파일에 있어야 한다.
- 실행 명령 및 확인 방법이 README에 기재되어야 한다.
- 완료/부분/검증 대기/미구현 항목을 분리하고 실제 수행한 테스트만 보고한다.
- 다음 단계로 넘어가며 누적된 기능이 깨지지 않는지 확인한다.
