# 2026-10-29 — 훈련 시설/AP 목표·자동 휴식 진행 정보

전투·사냥·진화 수치 계산은 변경하지 않고, 기존 사육장의 자동 육성
상태를 플레이어가 실제로 이해할 수 있게 표시한다.

## 변경 사항

- 사육장 훈련 제어 아래에 **선택한 디지몬의 훈련 진행** 표시:
  현재 케이지/훈련 종류, 이동/대기/행동, 현재 능력치 또는 숨겨진
  종족 AP, 설정한 목표, 남은 수치, 목표 달성률 및 현재 훈련 주기.
- 기존 **자동 휴식 후 훈련 재개**가 실행 중일 때도 직전 케이지,
  해당 AP 목표와 현재 AP를 읽어 표시한다. 휴식 화면에는
  **HP 80% 이상 · 피로 30 이하**라는 실제 복귀 조건을 안내한다.
  다른 시설로 자동 이동시키거나 보상 지급 규칙을 변경하지 않는다.
- 이미 달성한 AP/능력치 목표를 재입력하면 작업을 시작했다고
  안내하지 않고, 기존의 훈련/휴식 명령은 그대로 둔다.
  이전 코드는 이미 달성한 목표를 확인하기 전에 활성 명령부터
  초기화해서 예상치 못한 중단을 만들었다.
- 선택 디지몬 변경 시 AP 목표 체크박스와 일반 능력치 목표
  체크박스를 구별한다. 저장 및 불러오기를 통해 자동 휴식 복귀
  대기 상태가 유지되도록 한다.
- **신규 세이브 필드 없음.** 진화 AP, HP, TP, 훈련 포인트,
  훈련 소모 시간과 Bit 비용은 이전과 동일하며, UI는 정해진
  구조의 저장 상태를 읽기만 한다.

## 검증

- `node --test tests/farm-training-progress.cjs`는 실제 시설에
  도착하여 목표 AP를 얻는 것, 진행 중 상태를 바꾸지 않고
  읽기만 하는 것, HP·피로로 인한 자동 휴식→시설 복귀,
  JSON 저장 상태 복원, 목표 중복 입력 및 진화/훈련 중단을 검증.
- `python3 tests/farm-training-progress-browser.py`는
  PC/모바일 터치 Chromium에서 실제 `index.html`과
  `standalone.html`의 진행 패널, 케이지 구매·AP 훈련,
  휴식/복귀 및 세이브 가져오기를 검증.
- 실제 HTML 소스는 `src/farm-core.js`, `src/hex-farm-ui.js`,
  `src/hex-farm.css`에서
  `python3 tools/sync-embedded-farm.py`로 동기화하며,
  GitHub Action 검사 통과 후에만 병합한다.

원작 ROM의 훈련 AP 획득 수치 및 상세 진화 조건은 여전히
부분적으로 검증되지 않은 확장판 임시 밸런스다.
