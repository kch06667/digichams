# 10차 — PC 사육장 도착 후 체류·주변 살피기

## 개발 목표
원작에서 확인되지 않은 신규 종족이나 도트는 추가하지 않습니다.
9차까지 구현된 PC 전용 자유 산책을 자연스럽게 보이게 하고,
기존 게임의 종별 GIF를 그대로 재사용합니다.

## 구현
- 선택형 자유 산책 ON일 때 해금 시설 방문을 마친 디지몬이
  **3~6초 체류**합니다. 시간은 개체 ID·방문 시설·게임 시간으로
  결정적이어서 같은 세이브로 재현 가능합니다.
- `farm.actors[id].idleTime` 기존 카운터의 음수 구간을 이용해
  체류 시간을 저장합니다. **신규 세이브 필드가 없습니다.**
- 도착 직후 `pose=0` — 기존 종별 기본 대기 GIF를 사용하며,
  약 2초 남았을 때 기존 반전값 `face`를 딱 한 번 변경하여
  주변을 살피는 듯한 연출을 더합니다.
- **게임 로직을 새로 만들지 않습니다.** 기존 `DCFarm.advance()`
  종료 직후 8차 확장 산책 목표의 도착 상태만 관찰해 보정합니다.
  `src/farm-core.js`, 진화/훈련/전투/포획 로직은 변경하지 않습니다.
- 기존 식사 예약, 체력/피로 자동 휴식, 수동 명령은
  체류를 언제든 중단시킬 수 있습니다.
- PC 사육장 생활 현황에 `구경` 인원을 추가합니다.
  화면 표시는 읽기 전용이며 모바일/원래 꺼짐 모드에는 적용되지 않습니다.

## 회귀검사
- `node --test tests/pc-ranch-free-roam.cjs tests/pc-ranch-life-routine.cjs tests/pc-ranch-ambient-dwell.cjs`
- `node tests/pc-ranch-preview.cjs` — 실제 게임 PC Chromium 및 터치 미적용
- 기존 사육장/포획/챔피언십/Phaser 한 저장 파일 통합 검사

## 제한
현재는 **모션 연결과 짧은 체류**의 첫 작업입니다. 시설별 전용 모션
(예: 별도 앉기/잠들기/관찰)은 NDS 애니메이션 인덱스 용도 검증 이후
적용해야 합니다. 실제 화면의 미학적 완성도는 사용자의 Windows PC에서
별도 검수합니다. 원작 자산·ROM·EXE/ZIP 공개 배포하지 않으며
해당 PR 및 상위 모든 Draft PR은 `main` 자동 병합 금지입니다.
