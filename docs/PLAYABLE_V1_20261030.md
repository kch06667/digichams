# Playable 1.0 candidate — first player-facing slice (PR61)

This project is **not being claimed as finished or NDS-perfect**. PR61 changes
two visible obstacles to enjoying what already works: a temporary demonstration
arena and manual private-art setup. It does not change battle AI, damage,
evolution, save format, or tournament rules.

## Windows PC — start the actual game in one command

From your EXISTING current GitHub checkout, not an old ZIP:

```powershell
git pull origin main
py -m pip install Pillow
```

After updating, **double-click `PLAY_ON_PC.bat`** at the repository root.
The launcher opens the existing original `index.html` game in your PC
browser and keeps a local HTTP server running until its window is closed.
If Python or Pillow is missing, the window displays the required setup
without silently downloading/installing anything. You can alternatively
run `py tools/play_local.py` from the terminal as before.

The launcher checks `assets/species-catalog.json` and all 216 local species
against the conversion catalog, per-species manifest, and 13 required motion
spritesheets. If the cache is incomplete, it invokes the existing
`tools/export-phaser-roster.py` **locally** to prepare 216 × 13 animations.
First run can be substantial. **As of PR64, if only 1 or 2 species are
missing or corrupt, only those species are regenerated** instead of
rebuilding all 216. A complete cache is reused without any conversions.
A malformed catalog is rejected with a clear diagnostic, not silently deleted. It then serves the **actual original**
`index.html` at `http://127.0.0.1:8000/index.html` and opens the browser.
The Phaser combat canvas still loads only the current 1–6 combatants' sprite
sheets per match, not all species at once. Original GIFs and new PNG sheets
remain under Git-ignored `phaser-lab/local-assets/`.

If Pillow is missing, install it using the command above. If
`assets/species-catalog.json` is missing, restore the owner's original
local indexed art; the launcher will NOT silently download ROM/art or
substitute a different species.

For emergency original-game debugging, `py tools/play_local.py --skip-art`
serves the same game but may show temporary procedural Digimon bodies.
Do not confuse that mode with the full-original-sprite experience.

## Android on the same trusted Wi-Fi

```powershell
py tools/play_local.py --lan
```

**Explicit caution:** `--lan` binds an unauthenticated static file server to
all local interfaces and makes locally converted original art downloadable by
any device that can reach this port. Use only on a trusted private network,
never on public Wi-Fi or an Internet-exposed host. Find the PC LAN IP and on
the phone browse to `http://PC-LAN-IP:8000/standalone.html` (or
`index.html`); the phone and PC browser have **separate localStorage saves**.
You must transfer a save deliberately; the launcher never synchronizes it.
Normal mode binds loopback only. `--port 8001` avoids a port conflict;
`--no-browser` disables desktop browser opening.

## Player-facing combat graphics

- Phaser's existing saved-state protected 1–3v3 fights and championships now
  use an **original code-drawn pixel field** with distant hills, arena wall,
  tiled floor, side zones, central marker and compact in-battle HUD. It is
  a custom new scene, NOT an extracted or verified NDS battle backdrop.
- Every fight displays **original GIF X/Y participants** or explicitly marks
  any missing participants as temporary placeholders, instead of implying
  they were converted. The player now sees if their private art is missing.
- Existing source-derived attack/hurt/KO/victory actions, 2D knockback and
  real-hit sparks, winner animation, result staging, verified backups and
  auto-save/reload remain untouched.

## Testing and release gate

`tests/test_play_local.py` checks the 216-species cache readiness contract,
missing files, bad identity, repeat reuse and invalid ports without a real
ROM or licensed art. The existing real original-game Chromium PC/touch
`tests/phaser-production-default-browser.py` asserts the pixel arena,
participant-art coverage, same-tab combat, guarded result/reload and failure
fallback. `tests/phaser-216-browser.py` checks all six original private GIF
actors on the playable 3v3 stage in PC and touch emulation. Prior original
journey, hunting, training, evolution, mobile longplay and legacy workflows
must continue to pass.

This does **not** prove actual Android physical FPS/process-kill recovery,
all 216 motions against original NDS video, original ROM effects, PWA offline
support for the owner's private art, or a general public redistributable build.
No ROM, private sprite GIF/PNG output, saved game, or ZIP is committed.
