# 시스템·데이터 계약 (개발 가이드, 구체 타입은 Codex 분석 후 확정)

## 저장 상태 분리
- `world`: 게임 시간/배속/계절/달력/이벤트 발생 ID 및 스케줄러.
- `player`: 테이머 랭크, 돈, 해금, 도감·타이틀·본편/확장 리그 진행.
- `speciesCatalog`: 불변 종 ID, 기본 특성, 기술 허용 목록, 필요 G, 진화 분기 목록, 로스터 구분(원작/확장), 데이터 출처.
- `digimonInstances`: 유니크 개체 ID, 종/성장단계, 8성격, 25기질, 6개 IV, 기본 훈련 수치/최종 전투 수치, 관계 및 훈련 목표, 체력/스트레스/배고픔, 수명/디지에그 횟수, 승패·부상/질병 기록, 진화 기억, 현재 위치(활동/보관/출전/야생).
- `farm`: 서로 연결된 육각형의 좌표 및 슬롯, 사용 중 시설, 시설 수용력·G 제한, 음식 객체·시간 경과, 대기 행동/이동 목표·예약.
- `moves`, `battle`: 기본/고유/보조 기술/호환·숙련·TP, 팀/개별 전술, 쿨다운, 행동 우선순위, 관계 합동기.
- `npcs`: 고정 라이벌 3인의 개별 성장·전적·진화·스킬·이벤트 상태, 전문 테이머/챔피언/게스트 로스터, 랜덤 엔드게임 시드.
- `quests`: 퀘스트 ID, 진행 상태, 진행 목표, 해금 트리거, 선택형 여부, 보상 지급 ID 및 중복 지급 방지.
- `settings`: 힌트/상세 진화, NDS/현대 레이아웃, 자동 육성, AI 전술, 저장 버전 등.

## 핵심 분리 규칙
1. **원작 수치** vs **확장 설계** vs **임시 값**의 출처를 모두 남긴다. 원작 ROM 미확인 숫자를 무조건 확정치로 쓰지 않는다.
2. **기본 능력치/훈련 성과**와 **25기질 및 IV에 의한 전투 적용값** 분리. 진화 조건은 별도 육성 능력치·카운터를 참조. 모든 IV를 진화 조건에 직결하지 않는다.
3. **보관소 스테이시스:** 입출고로 활동 여부 교체, 저장 중 수명·건강/배고픔 타이머 동결, 출전 금지. 입고/출고·용량·중복 소유 트랜잭션 테스트.
4. **자동 훈련 틱:** `시설 점유→실제 이동→모션 완료→HP/상승/하락 한 번만 정산→중단 검사→다음 틱`. 미니게임 스킵은 틱 건너뜀 금지.
5. **AI/전술:** 우선순위 조절만 허용, TP·거리·호환·상태·합동 조건 모두 만족해야 실행.
6. **랭크 및 원작 대회 조건:** 퀘스트/전문 테이머 이벤트를 선행 조건으로 끼워 넣지 않는다. 후반 리그는 별도 세이브 플래그.
7. **보상 멱등성:** 일정/랭크/퀘스트 완료 시 저장-불러오기 또는 프레임 드랍으로 두 번 지급하지 않는다.
8. **오프라인 진행 없음:** 게임이 닫혀 있는 동안 일반 시뮬레이션 시간은 흐르지 않는다(초기 정책).
9. **화면 레이아웃 무관:** NDS/현대형 화면 전환은 UI만 변경하고 시뮬레이션/카운터에 영향 없음.

## 코드 구조 예시 (처음부터 모든 빈 모듈을 만들 필요는 없음)
`src/core/{clock,events,save}`, `src/model/{species,instances,stats}`, `src/game/{farm,training,evolution,hunting,battle,tournaments,npcs,quests}`, `src/ui/{farm,panels,combat}`, `data/{original,expansion,provisional}`, `tests/`.

## 검증 가능한 핵심 테스트
- pause/1x/2x/4x 동안 이벤트 정확히 한 번, 저장 복구 후 진행 시 예약 보전.
- 훈련 시설 착지 시까지 보상 0, 애니메이션 사이클 종료마다 1회, 상승/하락/HP 동시 처리, 중지 이후 보상 0.
- 저HP 자동 휴식, 충분 회복 뒤 예약 복귀, 시설 사용 중 경쟁 및 취소 충돌 없음.
- 바닥 먹이→디지몬 이동→먹기→영양 반영, 부패/질병 카운터 추적.
- 활동 G 초과 시 보관소에서 출고 차단, 보관 개체의 수명/HP/배고픔 동결.
- 다른 동일 종 개체 6IV/25기질 달라도 진화 조건 동일(기질이 진화 통계 직접 보정 안 함).
- 모든 IV 값 하위권이어도 훈련으로 주요 대회 클리어 가능(모의 전투 회귀 테스트).
- 기술 부적합 종에게 전용 기술 계승 불허, 고유 기술 상실 없음.
- 퀘스트 미완료로 원작 타이틀전 참가 제한되지 않음.
- 라이벌 성장/전적 및 퀘스트 중간 단계가 저장/재개 후 유지.
- 한 엔드게임 랜덤 NPC에서 불가능한 기술/합동기 생성하지 않음.
