# Phase 1 원작 재현 — 첫 플레이 검수표

> 본 문서는 실제 플레이로 직접 확인하는 **테스트 요구사항**이다. 현재 체크박스는 완료 체크가 아니라 *향후 검사 항목*이며, 이 문서를 추가하는 것 자체는 플레이/브라우저/Windows 테스트 통과를 뜻하지 않는다.
> 기준: `main` README / `src/evolution-core.js` / `src/battle-core.js` / `phaser-lab/index.html`을 2026-10-31 확인. 기존 코드가 일부 기능을 갖춰도 원작 동일성은 별도 검증.

## 한 개체의 핵심 플레이 시나리오 (P0)
1. Windows에서 실행 파일 **더블클릭** → 게임 창 한 개 → 새 게임 생성.
2. 사냥 지도에서 원작 방식으로 디지몬 포획. 실패/재도전/다른 지역의 잠금 여부 확인.
3. 동일 개체가 케이지에 들어오고, 케이지 개요가 **원작처럼 두 줄**로 보임.
4. 케이지 내부에서 배고픔/먹이 여러 입 먹기/휴식/훈련 공격 모션을 보고, 훈련 수치를 확인.
5. 조건을 달리한 두 개체가 **서로 다른 진화 분기**를 밟을 수 있어야 함. 원치 않는 진화 결과도 억지로 막지 않음.
6. 해당 개체로 대회 출전 → **동시 AI 이동/공격/피격/넉백/필살기/승리** → 결과 판정과 보상.
7. 대회 결과로 가능한 해금(원작에서 해당하는 요소) 발생 → 새로운 육성/포획 도전.
8. 게임 종료 후 다시 실행 → 같은 개체 ID/능력/진화/진행/해금/대회 상태를 불러오고, 보상을 두 번 받지 않음.

## 검수표
| 영역 | 구체적 조건 | 현재 판정 |
|---|---|---|
| 실행 | 실제 Windows EXE가 무창/에러 없이 정상 시작 | 미검증 |
| 화면 | 한 창의 케이지 두 줄 개요, 하단 실험창/긴 스크롤 없음 | 미구현·미검증 |
| 케이지 | 케이지 간 전환/내부 생활 및 개체 배치, 원작 환경/효과 | 부분 구현·차이 검증 필요 |
| 포획 | 로프 묶기·당기기·집어올리기, 실패·저장·등록 | 부분 구현·차이 검증 필요 |
| 육성 | 먹이 여러 입, 훈련 공격 동작, 상태/시간/수치 원작 기준 | 부분 구현·차이 검증 필요 |
| 진화 | 종별 분기·우선순위·결과 연출 및 예상 밖 진화 | 부분 구현·차이 검증 필요 |
| 전투 | 동시 AI 전투, 모든 핵심 애니메이션, 넉백/타격음, 메인 게임 통합 | 부분 구현·차이 검증 필요 |
| 대회 | 원작 대회 구성/상대/보상/해금, 개체별 지속 기록 | 임시 규칙 포함·검증 필요 |
| 저장 | 동일 개체 한 세이브, 복구/중복정산 보호 | 부분 구현·Windows 미검증 |
| 라이선스 | ROM·원작 추출 그래픽의 GitHub/공개 배포 제외, 배포권 검토 | 배포 전 검토 |

## 데이터 검증 방식
각 규칙/에셋은 다음 태그 중 하나를 달아 추적한다.

- `ROM_CONFIRMED`: 원본 ROM/공식 자료에서 실제 구조나 값을 확인하고 검증 자료를 기록.
- `PLAY_CONFIRMED`: 실제 원작 플레이 영상/사용자 재현으로 동작만 확인; 정확한 수치는 보류할 수 있음.
- `GUIDE_DERIVED`: 원작 공략 등 2차 근거. 충돌 자료·버전이 있으면 함께 기록.
- `TEMPORARY`: 현재 확장판 시연값/임의 밸런스. 원작 동일성 주장 불가.
- `UNVERIFIED`: 검증되지 않은 항목.

원작 숫자가 확인 안 됐을 때는 임시 수치를 그대로 ‘원작’이라 부르지 말고, 조정 목표·근거·테스트를 붙인다.

## 이미 존재하는 테스트 진입점 (테스트 실행 전 확인)
```bash
npm run test:dev
npm run test:farm
npm run test:evolution
npm run test:hunt
npm run test:battle
npm run test:championship
```
위 명령은 package.json에 정의되어 있으나 **이 체크포인트를 작성하면서 새로 실행한 결과는 없다**. 정상 종료·원작 패리티·Windows 실기 QA는 각각 다른 검증이다.

## 출시에 필요한 실물 증거
- 하나의 Windows 게임 창에서 케이지 두 줄 개요, 케이지 내부, 훈련, 진화, 대회, 결과 화면의 연속 스크린샷.
- 종별 이동·공격·피격·기절 애니메이션 및 동시 AI 타격을 보여주는 짧은 캡처.
- 동일 개체가 사냥부터 대회까지 이어지고 저장/재개 가능한 재현 절차 및 해시·테스트 기록.
- 원작과 달리 임시로 구현된 규칙의 목록.
- 저작권 자산이나 개인 세이브가 공개 저장소에 포함되지 않았다는 검증.
