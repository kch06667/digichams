# Codex에 보내는 ROM 분석 지시문

프로젝트의 `ROM_ANALYSIS/` 폴더를 확인하라. `rom_metadata.json`과 `rom_file_manifest.csv`는 한국어판 NDS ROM에서 직접 추출한 검증된 파일시스템 메타데이터다. **원본 ROM 자체는 이 저장소에 없다.**

1. 먼저 `README_FIRST.md`, 파일 목록, `analysis_targets.md`를 분석해 디지몬 종/진화/기술/전투/훈련/대회/텍스트 데이터가 있을 법한 파일과 실행 코드 영역의 조사 우선순위를 정하라.
2. `verified`, `inferred`, `unknown` 3단계로 근거 수준을 표시하라. 파일명만 보고 진화 조건이나 수치를 만들어내지 마라.
3. 원본 ROM이 별도 로컬 작업 환경에서 제공되면 `extract_nds_files.py`로 추출하고, 해당 바이너리 파일을 실제로 분석하라. 원본을 수정하지 마라.
4. JSON/CSV로 재구성 가능한 게임 데이터 스키마와 추출기를 단계별로 구현하고, 추출값마다 원본 파일 경로·오프셋·검증 방법을 기록하라.
5. 아직 검증하지 못한 데이터는 `unknown`으로 남겨 두고 웹게임 구현 시 임의의 원작 값으로 확정하지 마라.
6. 원본 ROM, 사운드, 그래픽 등 저작권 자산은 GitHub에 커밋하지 마라. `rom_sha256`은 파일 식별·검증 용도로만 사용하라.

첫 작업은 분석 계획과 탐색 후보를 보고하고, 근거가 확보된 데이터만 추출하는 것이다.
